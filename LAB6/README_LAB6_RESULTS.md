\# Lab 6: Code Coverage and Branch Coverage Analysis



\## 1. Overview



This project demonstrates code coverage and branch coverage testing

for the Credit Card Rewards application using Python, pytest, and

Coverage.py.



The objective is to measure how effectively the test cases exercise

the application's statements and decision branches, identify

untested paths, and improve test completeness.



\## 2. Objectives



\- Understand the difference between code coverage and branch coverage.

\- Measure statement and branch coverage using Coverage.py.

\- Test normal inputs, invalid inputs, boundary values, and alternative

&#x20; decision outcomes.

\- Generate terminal reports as evidence of test coverage.

\- Maintain separate test files for code coverage and branch coverage.



\## 3. Tools and Requirements



\- Python 3.12

\- pytest

\- Coverage.py

\- Git and GitHub
